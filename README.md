# Introduzione a React.js

**React.js** è una libreria open-source sviluppata da Meta (ex-Facebook) per costruire **interfacce utente** basate su componenti :contentReference[oaicite:1]{index=1}.  
Utilizza un **Virtual DOM**, che aggiorna solo le parti modificate, migliorando le prestazioni :contentReference[oaicite:2]{index=2}.

**Ideale per**:
- App web interattive (single-page)
- UI modulari e riutilizzabili
- Integrazione con React Native, Next.js, Redux, ecc.

**Punti chiave**:
- Architettura basata su componenti e props
- React Hooks per stato e side‑effects (useState, useEffect…)
- Ecosistema esteso (routing, gestione stato globale…)

**Prerequisiti**:
- HTML, CSS, JavaScript
- Node.js/npm

**Primi passi**:
```bash
npx create-react-app nome-app
cd nome-app
npm start
